# 🎮 Neon Edition Tic-Tac-Toe

A modern and interactive Tic-Tac-Toe game developed using HTML, CSS, and JavaScript. This project features an attractive neon-themed user interface, smooth animations, and an intelligent computer opponent.

## ✨ Features

- 🎨 Attractive Neon UI Design
- 👥 Player vs Player Mode
- 🤖 Player vs Computer Mode
- 🧠 Medium-Level AI Opponent
- 📊 Live Scoreboard
- 🔄 Restart Game Option
- 🗑️ Reset Scores Option
- 📱 Responsive Design
- ⚡ Smooth Animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start playing and enjoy!

## 🎯 Project Objective

The main objective of this project is to improve frontend development skills and understand JavaScript game logic, event handling, DOM manipulation, and basic AI implementation.

## 👨‍💻 Developer

Created as a beginner-friendly web development project to practice frontend programming and interactive user interface design.
